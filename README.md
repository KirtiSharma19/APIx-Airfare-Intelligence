# APIx — Real-time Airfare Price Index

A web platform for monitoring, analyzing, and visualizing airfare price movements in India.

## Features
- Real-time airfare data monitoring
- Route-weighted Airfare Price Index (APIx)
- Fare anomaly detection
- Fare fingerprinting & deduplication
- Airfare Time Machine
- Interactive dashboard
- AI-assisted policy brief generation

## Tech Stack
HTML • CSS • JavaScript • Python • Streamlit • Pandas • Plotly
